# Azure Usage Forecasting

## 📌 Project Overview
This project aims to forecast Azure cloud usage by preparing high-quality datasets.
Milestone 1 focuses on data collection, cleaning, and preparation of economic datasets
required for future forecasting models.

---

## 🗂️ Milestone 1: Data Collection & Preparation

### Objectives
- Collect external economic and usage-related datasets
- Clean and preprocess raw data for consistency
- Handle missing values and duplicate records
- Prepare structured datasets for feature engineering

---

### Tasks Completed
- Imported raw economic dataset
- Checked dataset shape, columns, and data types
- Removed missing values using appropriate methods
- Eliminated duplicate records
- Standardized column names
- Saved cleaned dataset for further processing
