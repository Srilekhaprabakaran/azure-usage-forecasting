# Milestone 3 – Machine Learning Model Development

## Objective

The objective of Milestone 3 is to build and validate machine learning models for forecasting demand using the prepared dataset.

## Dataset

The project uses the **economic feature engineered dataset** created in Milestone 2.
This dataset contains processed features that help in training forecasting models.

File used:

* economic_data_feature_engineered.csv

## Tasks Completed

* Loaded the feature engineered dataset.
* Split the dataset into training and testing sets.
* Trained machine learning models for forecasting.
* Evaluated model performance using evaluation metrics.
* Selected the best performing model for prediction.

## Model Evaluation

The models were evaluated using the following metrics:

* **MAE (Mean Absolute Error)** – Measures the average absolute difference between predicted and actual values.
* **RMSE (Root Mean Square Error)** – Measures the square root of the average squared differences between predicted and actual values.

These metrics help determine the accuracy of the forecasting model.
